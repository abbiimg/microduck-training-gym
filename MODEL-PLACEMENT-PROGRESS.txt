How placement was established
Author assembly reference labels identify each placed component exactly; source
model UUIDs were not invented inside STEP. Each model is taken from its own
recovered placed geometry rather than assuming matching dimensions establish
canonical definition equivalence. Exact author footprint origins are removed;
bottom-side inverse rotation is applied. Original local dimensions are kept.
Source rotation is already baked into the recovered native footprint geometry,
so each local model includes that same source rotation. The saved native
footprint angle is checked as 0; subsequent edits can move/rotate the footprint
and its attached model together.

The author exporter divides source coordinates by 39.37, while the native
recovery uses exact mil 0.0254 mm. This is a 2 ppm difference. We map individual
footprint origins to their exact native coordinates without scaling local part
geometry or globally forcing author PCB bounds to fit. Source board bottom Z 0
and top Z 1.600050800102 mm were independently verified from the physical stack
and author Board solids. Both IMU author outlines still differ from the current
source cache; these attachments do not establish enclosure/board revision fit.

An asymmetric synthetic KiCad 10.0.7 fixture established top/bottom translation,
rotation and angle conventions. The native exporter puts the current nominal
1.600048 mm boards' top model datum at 1.595048 mm and bottom datum at -0.085 mm.
These measured exporter offsets are retained and reported; models are attached
relative to their board-side surface, with no guessed zero-offset world models
or compensating substrate rescaling. Viewer/exporter offsets and physical
stackup/model tolerances still require mechanical qualification.

The detailed CAD check compares source-placed geometry to local models, then
compares exact-reference native STEP instances with the fixed calibrated pose.
It uses analytic bounds, solid counts, volume and both directional Boolean
differences. No free alignment, registration or fitting is allowed. A displaced
synthetic model must fail. Hash-bound receipts permit later fast checks without
claiming the expensive kernel checks were rerun. See per-project
model-export-validation.json and audit/kicad-model-export-validation.json.
Blender bounds are compared with analytic STEP bounds, with 0.02 mm tolerance;
this is a bounded mesh-import check, not a component-dimension/fit certification.

All five detailed CAD checks passed for all 84 attachments. Both directional
Boolean differences were zero; maximum analytic bounds residual was about
9.41e-12 mm. All five Blender package checks passed; maximum STEP/Blender bounds
difference was about 2.82e-6 mm. Actual top/bottom preview images were opened and
inspected; audit/pcb-model-visual-review.json binds that review to their hashes.

Reusable commands
Run tools/attach_author_models.py prepare --candidate <candidate> with KiCad's
pcbnew Python; geometry with CadQuery/OCP Python; attach with pcbnew Python.
Existing destinations require --overwrite-generated; preserve edits first.
The build protects changed generated boards on repeat attachment and preserves
the original integrated parents. Direct board serialization avoids expanding
the project defaults. Models also reload from the local footprint libraries.

Run tools/verify_kicad_model_exports.py with CadQuery/OCP for fresh heavy CAD
checks. Use verify_kicad_model_integrity.py for hash-bound receipt checks and
verify_pcb_model_review_package.py for the Blender/native DRC package checks.
tools/build_pcb_model_blender_review.py runs in a separate Blender background
process with --factory-startup and a candidate after --. It never clears the
user's live scene. The installed live Blender MCP connection was unavailable
during this phase; no integration was reinstalled or unrelated document opened.

tools/verify_author_step_geometry.py separately compares all exact source
product definitions against the 22 recovered definition assets, with numerical
solid differences, asymmetric negative controls and sampled boundary distances.
Its report states finite-sampling limits; it does not claim topological identity
or original vendor model origins. verify_author_step_geometry_receipt.py checks
the saved evidence without silently repeating CAD kernels.

All 61 source-definition comparisons passed: 30 full Boolean/boundary checks
and 31 exact serialized-BRep duplicate checks across 22 recovered model types.
Directed difference volumes were zero. Maximum sampled boundary residual was
8.854e-8 mm against a 1e-5 mm limit. The preserved extraction index's earlier
metric-only flags describe that older extraction stage; this new separate
receipt adds the numerical geometry evidence and its stated limits.
