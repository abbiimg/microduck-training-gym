Source-clearance translation
project_source_clearances.py writes separate editing/kicad-source-clearances/
projects. The PCB and global project defaults are byte-identical to their
parents; explicit .kicad_dru rules add supported SAFE pair-specific checks.
The installed-decoder evidence in audit/source-rule-review.txt/.json establishes
raw mil values and source class indices. No SAFE/OTHER selector overrides were
present in these source boards. Placed source test-pad classes are guarded
against accidental ordinary-pad classification.

Supported native categories: straight/arc Track, ordinary SMD/PTH Pad, Via,
copper Graphic, and saved Zone regions. Positive copper intersections map each
zone back to source primitive IDs/layers and class6 fill/teardrop or class7 pour.
Regions with mixed class provenance use the maximum relevant limit. Edge rules
use conservative source outline11/cutout8 envelopes; symmetric two-drill checks
collapse directed limits conservatively. OTHER drill-to-drill checks include
actual drilled objects, including vias. Unmapped categories retain their prior
defaults; no severity-ignore rules or arbitrary zone priorities were added.
NPTH/source test-pad/text-image cases, exact edge categories, mask/paste and
regenerative copper still prevent a full source-rule-fidelity claim.

Eight isolated native KiCad 10.0.7 fixtures verified object types, layer scoping,
and clearance/edge/hole constraint selection. They exposed an important version
detail: explicit custom constraints can override higher global minima, despite
the manual's blanket wording. An unmapped Pad/Via pair kept its prior default
while a represented Track/Track pair used its explicit source value. Global
defaults therefore were not lowered. See audit/native-clearance-rule-review.txt
and native-clearance-rule-probes.json. The verifier checks the actual native
version before accepting that evidence.
Primary references: https://docs.kicad.org/10.0/en/pcbnew/pcbnew.html
and https://gitlab.com/kicad/code/kicad/-/raw/10.0/pcbnew/drc/drc_engine.cpp
