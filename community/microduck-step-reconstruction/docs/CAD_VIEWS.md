# CAD 三视图图册 / CAD view gallery

[返回首页 / Home](../README.md) · [改进参数 / Technical notes](../03_REVERSE_ENGINEERING.md)

全部图纸直接来自最终 STEP，使用第三角三视图布局并附轴测图。PNG 便于预览，SVG 可缩放。虚线表示隐藏边；淡色细线保留平滑边界。仅供几何展示，不是含公差的制造图。

All sheets are computed from the final STEP files using third-angle orthographic layout plus an isometric view. PNG is for preview; SVG is scalable. Dashed lines are hidden edges and lighter lines retain smooth boundaries. These are reference views, not toleranced manufacturing drawings.
