What must NOT be reclassified as silk
Used footprints also contain model/construction records on layer types
COMPONENT_SHAPE (observed ID48), COMPONENT_MARKING (49), PIN_SOLDERING (50),
PIN_FLOATING (51), plus DOCUMENT13 and TOP_PASTE_MASK7. These are not silk.
The older/revised boards have 16/14 explicit paste-layer FILLs; none were added
to this recovery. The revised PCB's one STRING is on layer5 TOP_SOLDER_MASK,
not silk. It says IMU_TO_DXL / V1.0A and remains unconverted here. Reassigning it
to silk would change the source, and reproducing it on mask needs separate
mask polarity/semantics review. ELE_PLACEHOLDER is an allocation/configuration
record, not a graphical primitive. Hidden footprint ATTR records with null
positions are not placed text.

Coordinates and side
The established observed-source profile uses PCB/footprint coordinates in mil
(0.0254 mm). lceda_pcb_geometry.transform applies local-Y reflection for bottom
components, then source CCW angle rotation, then component x/y translation.
The native board coordinate mapping finally flips global Y. Silk layer types
TOP_SILK/BOT_SILK swap on bottom components. CANVAS is viewport metadata and is
not applied as another geometry translation. These are the same source-frame
operations used by the previously verified pad conversion.

POLY is a continuous path: explicit coordinates plus L/ARC sweeps, or CIRCLE.
Native line/arc/circle geometry retains the source stroke width. Circles remain
native circles. SOLID silk FILL paths here are straight-edged polygons, retained
as filled native polygon graphics with source width. Only explicit silk records
are selected. Each native item's source type/ID, reference, geometry and UUID
is recorded for review; one source POLY can create several native segments.

PCB Designator ATTRs already have GLOBAL PCB x/y positions. Do not apply the
component transform to them again. All 62 placed references are visible,
positioned LEFT_BOTTOM records with source fontFamily=default, fontSize45 mil
and strokeWidth6 mil; their non-normalized angles include full turns and are
normalized modulo360, with sign inversion for the native coordinate frame.
Content, anchor, layer, mirrored/bold/italic flags and metric size/width are
mapped to editable native reference fields. Source default-font glyph geometry
is not recovered; native KiCad stroke text is an EXPLICIT substitute. Exact
glyph metrics, visual alignment and font parity remain unqualified.

Notably the two battery Designator ATTRs are on back silk with mirror=false.
That source setting is retained, producing two native nonmirrored-back-text
warnings. Do not silently mirror those labels merely to clear the warnings.

Implementation
tools/recover_footprint_silkscreen.py uses the separately pinned community
reader's geometry helpers. Arguments:
  --reader <Linux absolute reader path>
  --candidate <name>
  --source-root <optional absolute or asset-root-relative folder>
  --destination-root <optional absolute or asset-root-relative folder>
  --overwrite-generated  [only after preserving user edits]
  --drc-timeout <seconds> [default180]
Defaults read source-rules-projected parents, except battery uses the prior
graphic-corrected parent; output is editing/kicad-silkscreen-recovered/.
The root overrides allow integration onto the reviewed source-clearance copies.
Generator writes a pre-DRC geometry/library audit and records timeout explicitly.

3D placement evidence
All 62 placed components have nonempty 3D Model IDs/titles and nine-field
3D Model Transform metadata in their referenced DEVICE META.attributes, even
though the PCB COMPONENT.attrs do not repeat them. See
placed-device-model-metadata.json. Device/library defaults must be reconciled
with placed overrides before attachment. IDs often include a | suffix; retain
the complete identifier until its version/ownership semantics are established.

The documented transform specifies normalized model size, Z/X/Y rotations and
offsets relative to a top-side, unrotated footprint at origin. It recenters the
model at XY midpoint/minimum Z before scaling and rotating. A raw transform is
not a drop-in KiCad offset/rotation: source binary bounds/units and KiCad model
units/rotation order must first be qualified. Replay contains no MODEL-type
documents; recovery of actual model binary resources has not been established.
No substitute 3D models were attached by this work.

The revised-IMU supplier catalog already covers24 components/16 supplier IDs
with candidate models. Its dimensions/electrical/model-placement qualification
flags remain false. Similar titles or matching pad counts do not establish an
exact original model match.
